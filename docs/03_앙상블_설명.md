# 03. 부스팅 앙상블

노트북: `notebooks/03_부스팅_앙상블.ipynb`

Lv3에서 고른 단일 모델(약 0.904)을 넘어 점수를 본격적으로 올려보는 단계다. 결과적으로 여기서 0.94864까지 올랐다.

## 이 단계에서 새로 이해한 개념 3가지

### OOF (Out-Of-Fold) 교차검증

데이터를 5조각으로 나눠 4조각으로 학습하고 남은 1조각을 예측한다. 이걸 5번 돌리면 모든 데이터가 "학습에 안 쓰인 상태로" 한 번씩 예측된다. 이 예측(OOF)으로 점수를 재면 누수 없는 정직한 점수가 나온다. 실제로 이 OOF 점수가 리더보드랑 같은 방향으로 움직여서, 이걸 믿고 판단하면 된다는 걸 알았다.

### 앙상블이 왜 오르나

LightGBM·XGBoost·CatBoost·HistGradientBoosting은 점수가 비슷해도 **틀리는 샘플이 서로 다르다.** 확률을 평균내면 한 모델이 틀린 걸 다른 모델이 메워줘서, 단일 최고 모델보다 대체로 조금 더 높고 안정적이다. 이 "서로 다르게 틀린다"는 게 앙상블의 핵심이라는 걸 이해했다.

### fold 배깅 + early stopping

- fold 배깅: 각 fold에서 학습한 모델의 test 확률을 평균 → 분산이 줄어 더 안정적
- early stopping: 검증 점수가 안 오르면 나무 추가를 멈춤 → 나무 수를 자동으로 정해주고 과적합·시간도 줄여줌

## 실제로 한 것

1. 가지치기 진단: 정예 변수(PRUNED) vs 전체 변수(FULL)를 LightGBM OOF로 비교해서 점수 높은 쪽 채택
2. 4종 부스팅 OOF 학습: 각 모델을 5-fold로 학습해 OOF 점수 + 배깅된 test 확률 확보
3. 앙상블: 4모델 확률 평균해서 최종 예측
4. (선택) 가중치 탐색: 단순 평균 대신 모델별 가중치를 랜덤 서치로 살짝 조정

## 불균형 대응

지표가 balanced accuracy라서 `class_weight='balanced'`(또는 sample_weight)로 소수 클래스(fit·unhealthy)에 가중치를 줬다.
