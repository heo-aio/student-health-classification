# 3️⃣ 부스팅 앙상블 — 쉬운 설명

> 노트북: `notebooks/03_부스팅_앙상블.ipynb`
> 한 줄 요약: **강한 부스팅 4종을 정직한 교차검증으로 학습하고, 확률을 평균해 서로의 실수를 상쇄한다.**

## 이 단계를 왜 하나요?

Lv3에서 고른 단일 모델(~0.904)을 넘어 점수를 본격적으로 끌어올리는 단계입니다.
결과적으로 **0.94864**까지 올랐습니다.

## 핵심 개념 3가지

### 1. OOF (Out-Of-Fold) 교차검증 — 정직한 점수 측정
데이터를 5조각(fold)으로 나눠, 4조각으로 학습하고 남은 1조각을 예측합니다. 이걸 5번 돌리면 **모든 데이터가 "학습에 안 쓰인 상태에서" 한 번씩 예측**됩니다.
→ 이 예측(OOF)으로 점수를 재면 **누수 없는 정직한 점수**가 나옵니다. 리더보드와 방향이 같아요.

### 2. 앙상블 (여러 모델의 확률 평균) — 왜 오르나?
LightGBM·XGBoost·CatBoost·HistGradientBoosting은 비슷한 점수라도 **틀리는 샘플이 서로 다릅니다.**
확률을 평균내면 한 모델의 실수를 다른 모델이 메워줘서, 단일 최고 모델보다 대체로 더 높고 안정적입니다.

### 3. fold 배깅 + early stopping
- **fold 배깅**: 각 fold에서 학습된 모델의 test 예측 확률을 평균 → 분산이 줄어 더 안정적
- **early stopping**: 검증 점수가 안 오르면 나무 추가를 멈춤 → 나무 수를 자동으로 최적화(과적합 방지 + 시간 절약)

## 무엇을 했나요?

1. **가지치기 진단**: 정예 변수(PRUNED) vs 전체 변수(FULL)를 LightGBM OOF로 비교 → 점수 높은 쪽 채택
2. **4종 부스팅 OOF 학습**: 각 모델을 5-fold로 학습, OOF 점수 + 배깅된 test 확률 확보
3. **앙상블**: 4모델의 확률을 평균 → 최종 예측
4. **(선택) 가중치 탐색**: 단순 평균 대신 모델별 가중치를 랜덤 서치로 미세조정

## 불균형 대응

지표가 balanced accuracy이므로 `class_weight='balanced'`(또는 sample_weight)로 소수 클래스(fit·unhealthy)에 가중치를 줬습니다.

## 실행 팁
