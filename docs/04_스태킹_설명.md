# 4️⃣ 스태킹 & 최종 스퍼트 — 쉬운 설명

> 노트북: `notebooks/04_스태킹_최종스퍼트.ipynb`
> 한 줄 요약: **작은 이득을 여러 개 쌓아 1등(0.95198)을 추격하는 마무리 단계.**

## 이 단계를 왜 하나요?

0.94864 → 0.952+ 구간의 마지막 0.003은 **"새 알고리즘 하나"로 메우는 게 아니라 작은 이득을 5~6개 쌓아서** 메웁니다. 그 카드들을 모두 넣은 노트북입니다.

> **현재 결과**: 이 노트북의 스태킹 앙상블로 **0.94904** 달성 (제출: `submission_lv5_frac0.3_1seed_5fold.csv`).
> 단, `frac0.3`(데이터 30%·1seed·5fold)의 **부분실행** 값이라, 아래 실행 플랜의 ③④(full·멀티seed·10-fold·Optuna)까지 돌리면 더 오를 여지가 큽니다.

## 넣은 카드 (효과 큰 순)

| 카드 | 무엇 | 왜 오르나 |
|---|---|---|
| **원본 데이터 결합** ⭐ | Playground 데이터는 실제 데이터셋으로 만든 합성 데이터 → 원본을 train에 추가 | 진짜 분포 표본이 늘어남 (상위권 필수 기법) |
| **스태킹** | 4모델의 확률을 입력으로 받는 메타모델(로지스틱)을 학습 | "조건부 신뢰 규칙"을 데이터가 배움 (단순 평균보다 똑똑) |
| **Optuna 튜닝** | 부스팅 하이퍼파라미터를 똑똑하게 탐색(TPE) | 각 모델을 더 짜냄 |
| **seed averaging** | 같은 모델을 여러 seed로 학습해 평균 | seed 운에 의한 분산↓ |
| **클래스별 확률 보정** | 소수 클래스 확률에 배수를 곱해 경계 조정 | balanced accuracy(=macro recall) 전용 미세조정 |

## 스태킹이 앙상블과 뭐가 다른가요?

- **단순/가중 평균**: "모델 신뢰도"를 사람이(또는 랜덤서치가) 정함
- **스태킹**: 4모델의 OOF 확률(12차원)을 입력 변수로 받는 **작은 메타모델을 학습** → "CatBoost가 unhealthy라 하고 LGBM이 애매하면 → unhealthy" 같은 규칙까지 데이터가 스스로 배움

## 속도 문제의 해답: OOF 캐싱 ⭐

Lv3가 "매번 오래 걸리던" 문제를 여기서 해결했습니다.
한 번 학습한 모델의 OOF/test 확률을 디스크에 저장(`oof_cache/`)해두면, **앙상블·스태킹·보정 실험은 재학습 없이 몇 초**에 끝납니다.
→ 오래 걸리는 건 "학습 한 번"뿐. 실험 반복은 빠릅니다.

## 실행 플랜 (단계적으로)

| 단계 | 설정 | 목적 |
|---|---|---|
| ① | `RUN_FRACTION=0.3` | 파이프라인 검증 (빠름) |
| ② | `RUN_FRACTION=1.0` | 베이스 제출 → 리더보드 확인 |
| ③ | `+ RUN_OPTUNA=True` | 튜닝 반영 |
| ④ | `+ SEEDS=[42,2026,7], N_SPLITS=10` | 최종 풀파워 (GPU, 밤에 걸어두기) |

## 정직한 한마디

0.94904 → 0.95198의 마지막 구간은 **운(seed)과 미세조정의 영역**이기도 합니다.
상위권도 마법이 아니라 이 카드들을 전부 쌓은 것 + 제출 반복이에요.
**리더보드 점수를 쫓아 이것저것 제출하지 말고, OOF 기준으로 냉정하게 고르는 것**이 최종 순위를 지킵니다.
