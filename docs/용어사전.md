# 용어사전 (내가 헷갈린 것 위주로 정리)

프로젝트 하면서 막혔던 용어를 내 말로 다시 정리한 것. 노트북 보다가 막히면 여기서 찾으면 된다.

## 평가 · 검증

**balanced accuracy** — 클래스별 recall을 각각 구해 평균낸 점수. 불균형일 때 소수 클래스도 공평하게 반영한다. 이 대회 공식 지표.

**accuracy** — 전체 중 맞춘 비율. 불균형이면 함정이다. 다수 클래스만 찍어도 높게 나온다.

**recall (재현율)** — 실제 A인 것 중에서 A라고 맞춘 비율. 놓치면 안 되는 걸 얼마나 잡는지.

**교차검증 (CV)** — 데이터를 여러 조각으로 나눠 번갈아 학습/검증하며 점수를 여러 번 재는 방법. 운에 덜 흔들린다.

**OOF (Out-Of-Fold)** — 교차검증에서 학습에 안 쓰인 조각에 대한 예측. 모으면 누수 없는 정직한 점수가 된다.

**hold-out** — 데이터 일부를 떼어서 학습에 안 쓰고 최종 검증용으로만 두는 것 (예: 80/20).

**데이터 누수 (leakage)** — 검증/테스트 정보가 학습에 새어 들어가는 것. 점수는 좋아 보이는데 실제론 나쁜 함정. 파생변수 기준을 test로 계산하면 발생한다. (이거 때문에 계속 조심했다)

## 불균형 대응

**class_weight='balanced'** — 소수 클래스 오류에 더 큰 벌점을 줘서 모델이 소수 클래스를 무시하지 않게 하는 장치.

**층화 샘플링** — 표본 뽑을 때 원래 클래스 비율을 유지하며 뽑는 것.

## 파생변수 · 인코딩

**파생변수 (Feature Engineering)** — 기존 변수를 조합·변형해 새로 만든 변수. 예: 수면시간 → 권장 수면 부족분.

**서열 인코딩 (Ordinal)** — 순서 있는 범주를 숫자로 (low=0, medium=1, high=2). 순서 정보를 살린다.

**OneHot 인코딩** — 순서 없는 범주를 0/1 여러 칼럼으로. 숫자를 매겨서 없는 순서가 생기는 걸 막는다.

**상호정보량 (MI)** — 변수가 타깃과 정보를 얼마나 공유하는지 나타내는 값. 변수 고를 때 썼다.

## 통계 검정

**Chi-square 검정** — 두 범주형 변수가 관계있는지(독립이 아닌지) 검정.

**Kruskal-Wallis 검정** — 여러 그룹 간 값 분포가 다른지 보는 비모수 검정. ANOVA의 순위 버전이라 가정에 덜 민감하다.

**Cramér's V** — 범주형 변수 간 관계의 세기(0~1). 표본이 크면 p-value가 항상 작게 나오는 걸 보완해준다.

**효과크기 (Effect Size)** — "유의한가"를 넘어 "실제로 얼마나 큰가"를 보는 값 (eta², Cramér's V).

## 모델

**부스팅** — 약한 모델(작은 트리)을 순서대로 쌓아 앞 모델 실수를 뒤 모델이 보완하는 방식. LightGBM/XGBoost/CatBoost.

**배깅** — 데이터를 여러 번 뽑아 독립적으로 학습한 모델들을 평균. RandomForest가 대표. 분산을 줄인다.

**앙상블** — 여러 모델 예측을 합치는 것. 서로 다르게 틀릴수록 효과가 크다.

**스태킹** — 여러 모델 예측을 입력으로 받는 메타모델을 한 번 더 학습하는 2단 앙상블.

**early stopping** — 검증 점수가 더 안 오르면 학습을 멈추는 것. 과적합 방지 + 시간 절약.

**하이퍼파라미터** — 학습 전에 사람이 정하는 설정값(학습률, 나무 깊이 등). 튜닝 대상.

**Optuna** — 하이퍼파라미터를 똑똑하게 탐색해주는 라이브러리. 이전 결과를 보고 다음 후보를 고른다.

**과적합** — 학습 데이터에만 잘 맞고 새 데이터엔 못 맞추는 상태. 변수/모델이 너무 복잡할 때 생긴다.

## 기타

**seed / random_state** — 난수 고정값. 같은 seed면 결과가 재현된다. 여러 seed 평균이 seed averaging.

**Pipeline** — 전처리 + 모델을 하나로 묶은 sklearn 구조. 같은 처리를 일관되게 적용하고 누수를 막는다.

**합성 데이터** — 실제 데이터로 학습한 생성모델이 만든 가짜 데이터. Kaggle Playground 대회가 이 방식이다.
